VIctory Launcher 

        
A Windows launcher for VIctory, which runs the Xbox Series X|S release of Grand Theft Auto VI natively on Windows from files you supply. This build carries avatarmanz's VIctory-7900XTX, the fastest fork, with console wave64 made exact on 32-lane GPUs (NVIDIA) and codec_d's NVIDIA and 32 GB RAM work on top.
